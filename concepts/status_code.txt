status code tells the client what happens.

2xx -> ok
4xx -> cleint request problem 
5xx -> server problem


200 → OK
201 → Created

400 → Bad Request
401 → Unauthorized
403 → Forbidden
404 → Not Found

500 → Internal Server Error
